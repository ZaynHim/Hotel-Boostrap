# SDK Hotel

A simple hotel website about Brown's Hotel in London.
The same page is built two times: once with HTML and CSS, and once with Bootstrap.

## Pages

- **first-step.html**: built with HTML and my own CSS file (style.css)
- **second-step.html**: built with HTML and Bootstrap 5 classes only

Each page has a button that takes you to the other page.

## Sections

- Header with the hotel name and links
- Hero section with a background image and a welcome message
- Our Rooms: Dover Suite, Clara Dow Suite and Kipling Suite
- Dining: Charlie's Restaurant, Halal Bar and The Drawing Room
- Experiences: Festive at Brown's, Jazz Nights and Unique Experiences
- Contact section with the hotel address

## Tools

- HTML
- CSS (Flexbox)
- Bootstrap 5.3
- VS Code with Live Server

No JavaScript was used in this project.

## How to Run

Open the project folder in VS Code, then right-click on first-step.html
and choose "Open with Live Server".

## Notes

- The hotel information and images were taken from the official Brown's Hotel website.
- AI was used to help organize the layout of the elements.
